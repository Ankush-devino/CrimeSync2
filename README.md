**CrimeSync** is a unified criminal intelligence, threat response, and autonomous cyber defense platform engineered for law enforcement command centers, forensic investigators, and cyber defense response teams.

---

## 🚀 Key Modules & Capabilities

### 1. 🎛️ Command Center & Active Cases
- Real-time criminal network topology graph and eigenvector centrality analysis.
- Live Geo-Intelligence GIS mapping with suspect proximity radii and CCTV feed integration.
- Instant suspect dossier modal with behavioral flags, biometric indicators, and evidence manifest.

### 2. 🪤 Deception Network (Active Defense)
- Live radar sweep monitoring decoy breadcrumbs, fake database tables, and AWS canary tokens.
- Real-time tripwire incident stream with MITRE ATT&CK technique attribution.
- Cryptographic Steganography & Watermarking Lab embedding zero-width Unicode seals into sensitive FIR documents to catch internal leaks.
- Insider Threat Matrix tracking behavioral anomalies and access deviation scores.

### 3. 💥 Blast Radius & Cascading Impact Analysis
- Radial shockwave graph visualizing Hop 0 Ground Zero breach propagation across network layers.
- Real-time MITRE lateral kill-chain execution tracker.
- Exposed critical asset matrix with automated zero-trust circuit breakers.
- Automated Disaster Recovery Playbook with instant host isolation.

### 4. 🤖 AI Agent Sandbox & Red-Team Simulation
- Secure gVisor microVM runtime for containerized autonomous AI agents (`DeepSeek-R1`, `Gemini-1.5-Pro`, `Llama-3.3-CyberRed`, `Mistral-Large-2`).
- Real-time neural chain-of-thought stream and CPU/VRAM/Token telemetry.
- Multi-agent coordination and data delegation pipeline.
- Red-Team adversarial attack suites testing SQL injection honeypots and prompt injections.
- eBPF kernel syscall monitor intercepting unauthorized socket egress attempts (`sys_connect`, `sys_ptrace`).
- Autonomous evidence lab certifying Hawala transaction charts and wiretap audio transcripts with SHA-256 blockchain proofs.

### 5. 🚨 Threat Alerts & SIEM Intelligence Operations
- Centralized SIEM stream with severity and category classification.
- Alert Forensic Detail Inspector with MITRE ATT&CK mapping, raw network PCAP summaries, and fast SOC actions.
- Campaign Correlation Clusters grouping multi-event attacks into adversary campaigns (Aman Khan Syndicate, Farooq "The Shadow" Network).
- Threat Actor Attribution Dossiers with known TTP profiles and confidence ratings.
- Automated Security Orchestration & Automated Response (SOAR) playbooks.
- Real-time pipeline health telemetry for Suricata IDS, Wazuh EDR, AWS GuardDuty, and Deception Mesh.

### 6. 🧠 Knowledge Graph & Neural Reasoning
- Multi-entity relational graph connecting suspects, burner phones, shell corporations, bank accounts, and vehicles.
- Shortest path graph solvers and Hawala money trail tracing.

### 7. ⏱️ 4D Time Machine & Crime Timeline Reconstruction
- Chronological forensic event slider reconstructing case timelines minute-by-minute with synchronized CCTV logs and CDR tower handoffs.

## ⚡ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/VANSH-GUPTA254/CRIMESYNC.git

# Navigate to project directory
cd CRIMESYNC

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

### Build for Production

```bash
npm run build
```
